12 • Publish and indexing

Preview using desktop, tablet and phone icons. Resize each embed individually: Google Sites uses frames, not native page HTML; frame height may need adjustment and hovering does not work on touch screens. Check keyboard navigation and all links. Publish using a brand-based address such as vayutech-global-solutions if available. Set published site access to Public and leave the search-engine exclusion option unchecked.
